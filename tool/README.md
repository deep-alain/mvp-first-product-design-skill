# 离线 MVP 评审工作台

双击 `index.html` 即可使用。保持同目录下 `app.js`、`model.js`、`style.css` 文件齐全。不需要安装依赖、账号或 API Key；页面没有模型调用、联网请求或遥测。

可以填写需求前提和核心契约、整理功能的 Keep / Simplify / Defer / Remove 决策、标记核心功能、查看缺项及冲突提醒，并导出 Markdown 报告和 JSON 评审。JSON 可再次导入；页面不会自动保存，关闭前请确认文件已下载。

“载入虚构示范”用于熟悉流程。它会在替换已填写内容前确认。删除功能条目也会确认。导入格式错误时保留原内容。

工具整理用户输入，提示结构冲突；完整的产品判断请结合 `SKILL.md` 或你的研究进行。填满输入框不代表产品成立。

## 开发与测试

没有构建步骤。模型和报告生成代码在 `model.js`，界面在 `app.js`。修改后用 Node.js 运行：

```sh
node --test tests/model.test.js
```

测试覆盖核心功能取舍冲突、信息保真、无效导入和报告中的表格转义。浏览器交互仍需检查添加、删除、导入、导出及窄屏显示。
