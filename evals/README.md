# 行为评估用例

`cases.json` 是人工编写的虚构输入和评审标准，没有记录任何模型运行结果。它用于后续验证，不是已通过的效果基准。

## 运行方式

1. 在选定客户端明确加载本 Skill。
2. 每个用例开新对话，只提供 `prompt` 给被评估模型，不提供 `must` 或 `must_not`。
3. 保存完整输入、输出、日期、模型、客户端、Skill 的 Git 提交号及工具权限。
4. 对照标准逐项人工评审。允许不同合理措辞和方案，不用关键词匹配冒充行为正确性。

每条 `must` 可记 0（遗漏或相反）、1（提及但缺乏可执行判断）、2（给出清楚理由与合理行动）。任何 `must_not` 行为出现，标记严重失败并保留原文证据。按用例记录，不能只用平均分掩盖核心失败。

如做效果对比，基线组保持相同模型、用户输入和环境，但不加载 Skill；报告运行次数及差异。单次演示不支持一般化效果承诺。

建议结果结构：

```json
  "output_file": "实际保存路径"
}
```
